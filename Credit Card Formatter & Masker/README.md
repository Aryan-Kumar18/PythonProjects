A lightweight Python command-line utility that sanitizes, validates, and masks credit card numbers. The program accepts raw card inputs containing spaces or hyphens, trims surrounding whitespace, and strips delimiter characters using native string operations. It verifies that the input consists strictly of 16 numeric digits before identifying the payment network—such as Visa, MasterCard, or American Express—using string slicing and prefix matching. Finally, it securely masks the card details by shielding the first 12 digits behind asterisks while preserving the last 4 digits for clear, formatted identification.
